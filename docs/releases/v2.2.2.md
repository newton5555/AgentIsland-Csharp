# AgentIsland for Windows - v2.2.2 Release Notes

发布日期：2026-09-14

## 版本概述

v2.2.2 聚焦于日报体验的全面升级与多 Agent 数据观测深耕：日报窗口全面支持“概览”与各 Agent 专属 Tab 细分视图，支持深入查看每个 Agent 的 24 小时脉冲与模型树分布；支持自动纳入非置顶但有本地消耗的 Agent，杜绝漏计；优化了统一日期徽章弹窗交互；同时增强了 DeepSeek 本地多版本会话的去重解析能力。

## 核心更新

### 1. 日报多 Agent 专属 Tab 细分视图 (Multi-Agent Tabs)

- **多维切换**：日报卡片支持“概览（Overview）”与各活跃 Agent（Claude, Codex, OpenCode, DeepSeek, Antigravity 等）专属 Tab 间一键平滑切换。
- **细分下钻**：在单个 Agent Tab 中，提供该 Agent 专属的 24 小时消耗脉冲柱状图（Hourly Pulse）、模型细分比例树（Model Tree）、Token 用量与美元花费折算。
- **双端对齐**：WPF 原生客户端报告窗口与 HTML/JS 独立报告卡模板保持 100% 视觉规范与交互逻辑同步。
- **视觉精简**：去除了概览头部多余冗余的说明文字，整体视觉更加克制现代。

### 2. 动态自动纳入有消耗的非置顶 Agent (Auto-Joined Guests)

- **用量不漏记**：当天只要产生本地 Token 消耗的 Agent（即便未被置顶在灵动岛常驻显示），也会自动纳入日报概览与树状分布中进行统计呈现；无消耗的非置顶 Agent 继续保持干净排除。
- **日期徽章交互统一**：点击顶部日期徽章可直接唤起轻量日历选择器，方便快捷跳转至历史任意一天的日报卡片。

### 3. DeepSeek 多版本会话去重解析增强 (Deduplication)

- 优化 DeepSeek 本地日志解析机制，智能识别多版本会话写入与文件轮转情况下的去重判定，彻底避免重复会话计数。
