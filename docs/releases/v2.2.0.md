# AgentIsland for Windows - v2.2.0 Release Notes

发布日期：2026-09-09

## 版本概述

v2.2.0 继续围绕本地账本可读性和 Provider 识别质量做增强：新增按日查看的报告卡，把小时级 Token、日环比、缓存统计和 Agent→Model 明细集中到一个可导出的视图；同时补齐 Google Antigravity 动态模型代号及价格归一化，让本地费用统计不再把同一模型拆成多个内部编号。

## 核心更新

### 1. 日报卡

- 从灵动岛页脚、设置页或托盘菜单打开日报；支持当前日、历史日翻页和日报 PNG 导出。
- 以本地时区聚合 24 小时 Token 脉冲，显示峰值小时、前一日环比、活跃 Agent/模型数量。
- 以 Agent → Model 两级树展示当日明细；子项占比使用全局日总量口径，与周报/月报的占比规则一致。
- 所有数据来自本机已解析的 Token 事件；没有账本记录时显示空状态，不生成虚构会话数或费用。

### 2. 缓存与费用明细

- `ReportSlice` 现在同时保留小时桶、缓存读取量和缓存写入量，并按模型累计缓存读取。
- 对具备价格表的模型计算“原始输入价 − 缓存读取价”的节省金额；未知模型和不支持费用的 Provider 保持 `—`。
- Antigravity 解析缓存升级到 v3，模型归一化规则变更后不会继续复用旧缓存结果。

### 3. Antigravity 动态模型识别

- 覆盖 `MODEL_PLACEHOLDER_M318/M319/M320`（Gemini 3.8 Flash）、`M298/M299`（Gemini 3.7 Flash）、`M20/M132/M133/M187`（Gemini 3.5 Flash）和 `M50`（Gemini 3.1 Flash Lite）等本地记录形态。
- 为对应 Gemini 模型补齐输入、输出、缓存创建和缓存读取价格，账本统计按归一化模型汇总。

### 4. Provider 状态视觉

- Antigravity 工作态使用 Google 蓝、红、黄、绿四段色带；Codex 使用明亮紫色；DeepSeek 使用鲸鱼蓝并保留工作态游动/气泡效果，方便在双 Provider 状态下区分来源。
