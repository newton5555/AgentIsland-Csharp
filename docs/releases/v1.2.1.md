## 🌟 版本概述

AgentIsland for Windows v1.2.1 是专注于**桌面悬浮交互体验深度打磨、灵动岛紧凑态视觉重构、报告窗口多语言与健壮性强化**的维护与体验提升版本。本次更新重点解决了桌面常驻悬浮场景下长时间无操作的视觉避让问题、双 Agent 激活时的紧凑态死区冗余问题以及常驻用量数据显示保持，同时全量补齐报告窗口中英文本地化字典，并消除了并发测试中的调度偶发竞态。

## 🚀 核心更新与体验优化

### 1. 灵动岛无操作自适应收缩与悬停交互 (Island Adaptive Interaction)
- **15 秒无操作自动收缩 (15s Idle Collapse)**：
  - 用户无鼠标交互超过 15 秒后，灵动岛自动优雅收缩为紧凑胶囊态（Compact），极大减少对桌面日常工作区域的视觉干扰；
  - 鼠标重新悬停在灵动岛上方时，即刻恢复默认完整展开宽度（484px），无需点击。
- **移出区域即时防抖缩回 (Mouse-Leave Auto Collapse)**：
  - 在灵动岛处于展开或窥视（Peek）状态下，当鼠标指针离开灵动岛外框区域并经过 120ms 防抖判定后，自动平滑收缩复位；
  - 支持键盘 `Esc` 键快捷折叠灵动岛展开面板。
- **默认与悬停尺寸一致性**：
  - 明确默认状态与鼠标悬停 Peek 状态保持原 484px 完整宽度，兼顾信息丰富度与视觉沉浸感。

### 2. 双 Agent 紧凑态死区收拢与常驻用量数据保持 (Compact Geometry & Usage Pills)
- **中间黑色死区收拢**：
  - 解决双 Agent 同时激活时紧凑态中间存在 200px 无用黑色死区的问题，在紧凑态下自动收窄中间间距为 16px；
  - 确保单 Agent 与双 Agent 处于紧凑态时的外框宽度严格统一（关闭常驻用量时为 92px，开启常驻用量时为 300px），避免单双 Agent 切换时的尺寸跳变。
- **常驻用量数据显示保持**：
  - 修复开启“常驻显示用量（Always Show Usage）”后收缩到紧凑态时头部用量药丸被误隐藏的问题；
  - 紧凑态下稳定保留左右双 Agent 头部用量药丸（300px 紧凑胶囊），让关键额度/用量百分比时刻一目了然。

### 3. 用量与费用报告窗口体验升级 (ReportWindow & Localization)
- **全量中英文多语言本地化 (Full L10n)**：
  - 补齐 `ReportWindow` 所有 UI 元素与动态文案的中英文对照，包括窗口标题、时间周期（按天/按周/按月/自定义）、指标标签、费用图谱、格式化说明、文件保存状态与剪贴板提示。
- **保存与复制状态精准反馈**：
  - 修复此前导出保存文件时错误弹出“已复制到剪贴板”的问题，现精准区分“已保存到文件（Saved to file: {path}）”与“已复制到剪贴板（Copied to clipboard）”。
- **剪贴板并发抗争锁重试 (Clipboard Resilience)**：
  - 针对 Windows 桌面环境下其他第三方软件偶尔独占剪贴板的问题，内置 3 次指数退避休眠重试，避免剪贴板争锁抛出 COM 异常。
- **窗口单例激活与聚焦管理**：
  - 优化托盘和全局菜单唤起逻辑，已打开时检测 `.IsVisible`，自动从最小化恢复并平滑置顶前台聚焦，避免多实例重叠创建。

### 4. 并发调度与测试沙箱健壮性 (Concurrency & Test Harness)
- **并发调度队列冲刷与去重竞态消除**：
  - 优化 `StoreDispatcherConcurrencyTests` 调度器队列同步机制，彻底消除多线程并发刷新在极速完成场景下的时序抖动，测试套件运行稳定可靠。
- **xUnit 串行执行集合与配置沙箱**：
  - 使用 `[Collection("IslandSettingsTests")]` 严格隔离配置测试上下文，运行测试完全沙箱化，零污染本机用户的真实应用配置文件。
