# AgentIsland for Windows - v1.2.0 Release Notes

发布日期：2026-09-06

## 🌟 版本概述

AgentIsland for Windows v1.2.0 是本项目的里程碑重构与稳定化大版本。本次更新完成了从传统零散代码向**现代化企业级 C# 纯依赖注入架构（Pure DI）**的全面跃迁，引入 Generic Host 统一宿主、Polly 弹性网络重试、响应式强类型配置监听与插件化 Agent 体系；同时建立针对极端高负载场景的**真实业务上限并发控制（严格双 Agent）**与 **1 年（365 天，730+ 文件）最坏情况 I/O 压力测试**验证，并优化了全新安装后的开箱即用体验。

---

## 🚀 核心更新与架构升级

### 1. 现代企业级 C# 纯依赖注入架构 (10-Phase Modernization)
- **100% 纯依赖注入 (Pure DI)**：
  - 全面拔除历史代码中散落的全局静态单例（`_instance` / `Shared`）；
  - 全工程统一接入 `Microsoft.Extensions.DependencyInjection` 容器进行注册与解析；
  - 核心服务抽取清晰接口（`IIslandModel`, `IUsageStore`, `ICostStore`, `IActivityMonitor`, `IProviderVisibilityStore` 等）。
- **Generic Host 应用宿主与托管服务**：
  - 基于 `Microsoft.Extensions.Hosting` 编排应用程序生命周期；
  - 将后台轮询全面重构为基于 `PeriodicTimer` 的异步托管服务：
    - `ActivityMonitoringWorker`（活动状态监听）；
    - `UsagePollingWorker`（周期性额度刷新）；
    - `CostAggregationWorker`（费用与账本汇算）；
    - `UpdateCheckWorker`（版本更新检查）。
- **弹性网络管线与离线快速失败 (Polly Resilience)**：
  - 接入 `IHttpClientFactory` 并装配 Polly 弹性策略管线（指数退避重试、动态熔断与断路器机制）；
  - 引入 `INetworkConnectivityService` 与 `OfflineFastFailHandler`，在网络断开时毫秒级快速失败，避免后台网络请求挂起阻塞主线程。
- **强类型配置模式 (Options Pattern)**：
  - 采用 `IOptions<T>` 与 `IOptionsMonitor<T>` 响应式配置体系（`IslandDisplayOptions`, `PollingOptions`, `AlertOptions`, `ProviderVisibilityOptions`）；
  - 配合 `AtomicJsonSettingsStorage` 实现跨线程安全的原子化 JSON 设置读写。
- **插件化 Agent 扩展架构 (Plugin Architecture)**：
  - 建立统一的 `IAgentProvider` 接口契约与 `IAgentCatalog` 动态注册中心，替换原本散落在各处的硬编码枚举，新 Agent 扩展零侵入。
- **MVVM 规范化与窗口抽象**：
  - 引入 CommunityToolkit 风格的 ViewModel（`IslandViewModel`, `SettingsViewModel`, `UsagePageViewModel`, `CostPageViewModel`）；
  - 抽离 `IWindowService` 与 `IDialogService` 抽象接口，彻底解耦 UI 表现层与核心业务逻辑。

### 2. 真实场景极限负载与 1 年压力测试 (Worst-Case Stress Testing)
- **双 Agent 活跃跟踪上限契约**：
  - 结合开发者日常最高频的工作流，明确“同时最多跟踪 2 个活跃协同 Agent（如 Claude + Codex 并行）”的上限契约；
  - 引入 `SemaphoreSlim(2, 2)` 门控，杜绝多 Agent 并发扫描引发的磁盘 I/O 拥塞与饥饿。
- **1 年（365 天）历史转录数据压力仿真**：
  - 构造覆盖 365 天、包含 730+ 个密集历史会话文件的最坏情况（Worst-Case I/O）数据集；
  - **冷扫描（Cold Scan）**：首次冷启动全量扫描 1 年数据首屏呈现 **< 30ms**；
  - **热扫描（Warm Scan）**：缓存命中后的常规轮询 **< 1ms**；
  - 深度扫描期间 CPU 增量峰值 **< 5%**，物理内存平滑可控。
- **一键压测 UI 启动器**：
  - 新增 [`Launch-StressUI.bat`](../../Launch-StressUI.bat) 与 [`scripts/Launch-StressTestUI.ps1`](../../scripts/Launch-StressTestUI.ps1)；
  - 启动前自动侦测并清理陈旧互斥锁与残留进程；
  - 自动在屏幕正中央弹出设置/用量仪表盘，同时在屏幕顶部展开灵动岛卡片并锁定展示状态。

### 3. 开箱即用配置体验 (Fresh-Install Defaults)
全新机器或首次安装后的默认配置贴合主流开发者直觉：
- **额度显示模式**：默认开启“剩余额度（Remaining Quota）”，直观展示还剩多少可用额度；
- **费用统计显示**：默认关闭（Off），保障离线隐私，零多余网络开销；
- **视觉外观模式**：默认跟随模型（Follow Model），自动根据当前活跃 Agent 匹配主题色；
- **灵动岛胶囊条**：默认开启常驻显示用量（Always Show Usage），无需鼠标悬停即可获知 5 小时用量百分比。

### 4. 自动化测试体系跃升 (Test Automation)
- 全自动化测试用例扩展至 **42 项**（包含 STA UI 线程调度、MVVM 交互、Options 强类型配置、Polly 网络弹性与 1 年并发基准测试）；
- 引入沙箱数据目录隔离机制，杜绝测试过程与本机运行中实例的数据互扰。
