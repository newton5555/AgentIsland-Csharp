# AgentIsland for Windows - v2.2.1 Release Notes

发布日期：2026-09-09

## 版本概述

v2.2.1 针对桌面常驻体验与系统托盘视觉进行了现代化重构：彻底淘汰了 Windows Forms 原生白底直角托盘菜单，引入了契合 Windows 11 Fluent 规范的暗黑微卡片；新增了 70% 灵动岛透明穿透模式，让桌面常驻监控彻底告别误触；同时修复了高 DPI 150% 界面缩放下的初始居中偏差。

## 核心更新

### 1. 现代化系统托盘菜单 (ModernTrayMenu)

- 彻底替换旧版 Windows Forms `ContextMenuStrip`，告别 Win98 白底直角边框与左侧灰色图标槽（Gutter）。
- 重构为现代 Fluent 深色微卡片（#191A1F 黑曜石底色、1px 微透光玻璃边框、8px 柔和圆角）。
- 视觉风格克制现代：去除多余头部状态块与易渲染为黑块的 Emoji 图标，采用统一 12px 边距左对齐文本排版与平滑微胶囊 Hover 高亮。
- 投影收敛至 10px 精致微阴影（`BlurRadius = 10, ShadowDepth = 2, Opacity = 0.24`），配合 WPF 原生 `PlacementMode.MousePoint` 智能贴合鼠标光标并自适应屏幕边缘防溢出。

### 2. 灵动岛透明穿透模式 (Transparent Mode)

- 托盘菜单原“显示 / 隐藏灵动岛”功能升级为“透明穿透模式”与“常规交互模式”一键切换。
- **透明模式**：整岛进入 **70% 半透明状态**（`Opacity = 0.7`），并启用 Windows 内核级 **鼠标完全穿透**（`WS_EX_TRANSPARENT`）；用户可在监控模型进度的同时直接点击操作灵动岛后方的代码编辑器、IDE 标签或游戏窗口，不再发生遮挡与误触。
- **常规模式**：恢复 **100% 完整不透明度** 与悬停展开交互。
- 托盘右键自适应显示当前状态标签（`透明穿透模式 (70%透明)` / `✓ 恢复正常模式 (当前: 70%透明穿透)`）；左键单击托盘图标弹出时，自动安全重置回正常交互模式。

### 3. 150% 缩放初始居中修复

- 修复了在设置中配置 150% 界面缩放后，应用冷启动时初始岛向右偏离屏幕中心 225px 的 Bug。
- 优化 `IslandWindow` 初始化加载顺序：在计算水平屏幕居中前优先执行 `ApplyInterfaceScale()` 计算缩放后实际宽度（1350px），确保启动时 100% 像素级对齐屏幕正中。
