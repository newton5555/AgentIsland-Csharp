# AgentIsland for Windows - v1.0.1 Release Notes

发布日期：2026-09-05

## 🌟 版本概述

AgentIsland for Windows v1.0.1 是基于上游 Agent Island 2.1.2 原型提取为独立 C# (.NET 8 + WPF) 顶级工程后的首个稳定发布版本。该版本聚焦于解决长时间后台运行的物理内存占用过高与文件轮询 I/O 效率问题，引入 Windows 内核级物理内存修剪与流式增量解析缓存。

---

## 🚀 核心更新与优化特性

### 1. 物理内存深度回收机制 (Memory Reclaimer)
- **内核级工作集修剪**：新增 `MemoryReclaimer` 异步防抖组件。在用户禁用高负载 Agent（如 Codex）或清理历史缓存后，经过 600ms 异步防抖，自动触发 Gen 2 与大对象堆（LOH）碎片压缩，并通过 Win32 内核 API `SetProcessWorkingSetSize` 将未引用的物理内存页立即退还给操作系统。
- **空闲常驻内存减半**：闲置或后台常驻时的物理工作集（Working Set）从原先的 200MB+ 平滑回落至 **100MB 以内**。
- **修复元数据缓存泄漏**：修复了 `SessionScanner` 在禁用 Codex 时漏清理静态元数据缓存 `CodexMetaCache` 的历史问题。

### 2. 逆向流切片与对象池复用 (Zero LOH Allocation)
- **逆向流扫描**：`SessionScanner` 采用 `ArrayPool<byte>` 租借缓冲区与逆向流切片机制读取超长 JSONL 日志，仅在需要时解码首行元数据，杜绝因频繁读取长文件产生的大对象堆碎片。
- **静态文件指纹比对**：引入 `CodexMetaCache` 与 `LogParseCache` 文件指纹校验（mtime + 文件长度），未发生内容变动的会话日志跳过重复反序列化，避免多周期定时轮询时的高频 GC 压力。

### 3. 悬浮窗 AABB 命中测试粗筛
- `IslandWindow` 在执行昂贵的复杂几何与圆角命中测试前，先进行屏幕空间轴对齐包围盒（AABB）快速判断，过滤 95% 以上无效坐标计算，显著降低鼠标在屏幕上方滑过时的 CPU 开销。

### 4. 托盘图标句柄与预渲染缓存
- `TrayIconRenderer` 预渲染 32×32 纯净 Logo 底图，并按视觉活动状态缓存 `Icon` 句柄，轮询状态未变化时不重复触发 GDI+ 绘制。

## 🧩 支持的 Agent 矩阵
- **Claude Code**：会话探测、Token 统计、官方 Quota API 对接与历史账本分析；
- **OpenAI Codex**：会话元数据提取、转录事件跟踪与 Token 消耗统计；
- **DeepSeek Harness**：本地 `.dsh` zstd 压缩流事件解析与官方余额 API 查询；
- **Google Antigravity**：转录日志捕获与 Token 统计；
- **xAI Grok**：状态嗅探与用量查询；
- **Cursor IDE**：跨进程读取全局 SQLite 状态数据库（`state.vscdb`）。
